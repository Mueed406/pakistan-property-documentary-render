# Pakistan Property Group — Urdu Stock Documentary Cloud Rendering

Open-source production project for a real stock-footage documentary with Pakistani Urdu narration, subtitles, restrained motion graphics, and FFmpeg editing. The output is a review copy, **not automatically published**. Uses licensed Pexels B-roll with source attribution and clearly labels reported allegations.

The GitHub Actions workflow installs the free tools, generates speech, downloads the original moving footage, renders and checks the MP4, then attaches it to the workflow run as a downloadable artifact. Quality and factual review required before public YouTube posting.
