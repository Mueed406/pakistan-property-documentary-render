## Quality target and anti-patterns
- User requests rich, high-quality professional documentary video with actual moving motion graphics, not a static image/prompt.
- Preserve paper/newsprint/ripped-edge texture, archival photography, meaningful typography, visual parallax and dedicated full-screen graphics.
- Use actual downloaded creator motion elements *only if rights and integration are verified*; use our original FFmpeg/Python engine for physical paper transitions. Imported sprites should improve visual explanation rather than drown it with random movement.
- Keep 1920x1080 output, nominal 60fps, and original 25fps stock source cadence accurately described.
- Keep narration untouched unless a superior full voice is generated, approved and cues realigned.
- Preserve preceding full v2/v1 GitHub Releases, use a new release tag and never overwrite the known-good file.
- Review the 18s proof on real footage first; run full 410s only after actual proof passes.
- No claim of literal '100x better' without objective measures or user signoff.
- Maintain source-adapter tests, individual rights metadata and rendered MP4 QA.
