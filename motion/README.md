# Programmatic documentary overlays — Remotion

This is a real React + Remotion motion project with animated 3D-perspective plot geometry, camera parallax, timed counters, and Urdu typography.

Install: `npm.cmd install --prefix motion`.

Render 7-second **graphics test only**: `cd motion; npm.cmd run preview`.

Pass `backgroundVideo` to render over real stock video (must be a valid local Remotion `public/` relative path or authorized HTTPS URL). Without footage, the result is only a motion-design test, not a full documentary.

Confirm eligibility: https://www.remotion.dev/docs/license/pricing — individuals and teams of up to three may use the free tier. Never assume larger agencies automatically qualify.

Human art-direction approval is required before using this in the feature film.
